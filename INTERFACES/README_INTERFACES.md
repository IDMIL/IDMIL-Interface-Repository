This folder contains information on each version of the interfaces/control systems developed at IDMIL.
every interface version has its own folder containing: Software, Hardware, Media-Files, Documentation, 
and Projects. any change to an interface's hardware and/or software constitutes a new version, with its 
own record. If only one component changed, unchanged modules are linked back to the prior version rather
than duplicated.
